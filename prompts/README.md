# 判断规则与提示词库

这里沉淀可迁移的**判断标准**，不是声称适用于所有人的固定答案。每个模板都应说明适用范围、证据标准、排除项、不确定处理方式和版本。

## 目录

- [通用模板](general-template.md)：把一个模糊的信息需求变成可复用规则。
- [实战经验筛选](first-hand-practice.md)：寻找有实际操作与证据支撑的经验帖。

## 如何使用

复制模板后，把方括号内容改成你的任务；用几条虚构或授权样例检查边界，再逐步修订。将你使用的**规则版本**和人工复核结果一起记录，避免把某个模型的一次概率当成金标准。

欢迎提交新主题、反例和评估方法。请不要提交 API key、私信、未公开信息或未脱敏的真实帖子。
