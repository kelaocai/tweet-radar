# 找一手实战经验帖

**状态**：示例草案 · **版本**：0.1.0 · **适用范围**：寻找可迁移的技术或工作实践经验

## Goal

找到关于【技术/方法】的实际使用经验，帮助【目标读者】判断是否值得在【环境/任务】中尝试。

## Profile

【目标读者的经验水平和当前任务】。重视作者自己做过什么、怎么做、在什么条件下有效，以及遇到什么失败或限制；不以作者粉丝数、互动量或表达自信程度作为质量证据。

## 命中标准

满足主题相关性，并至少包含以下两类可观察信息：

1. 实际操作、配置、代码或步骤；
2. 使用环境、时间范围、规模或前置条件；
3. 结果、失败、权衡或具体数据；
4. 能让读者进一步核对的公开材料。

## 排除项

- 仅复述发布公告或他人观点，没有作者自己的实践信息。
- 仅包含教程关键词、产品链接或促销内容。
- 宣称“最好”“提升很多”等，但没有说清比较基准、方法和限制。
- 与目标技术相同，但解决的问题、环境或读者需求完全不同。

## 不确定处理

无法判断是否亲历或关键信息缺失时标为“需人工复核”。不要仅凭第一人称断言或互动量确认真实性。

## 虚构边界用例

- **预期命中**：开发者公开了迁移脚本、兼容版本、回滚步骤和两次失败原因。
- **预期复核**：帖子说“新工具快十倍”，没有测试方法、环境或基线。
- **预期不命中**：帖子只转发工具发布页并附购买链接。
